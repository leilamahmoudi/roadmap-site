# Phase 3: Plan the Architecture and Tech Stack

This session produces one document: `build-plan.md`.

Before creating the build plan, decide what tech stack and architecture make the most sense for this project.

## Run the Technical Interview

Ask Claude to guide you through the important technical decisions one at a time.

## Example Prompt

Read `project-owner-expectations.md` and the specialist roles defined for this project.

Act as a senior software architect and help me decide the architecture and tech stack before we create the implementation plan.

Use current best practices for products like this, but do not recommend technologies just because they are popular.

For each important technical decision:

1. Explain what decision we need to make.
2. Recommend the option you think fits this project best and explain why.
3. Show the strongest alternatives and their trade-offs.
4. Explain which product requirements or specialist perspectives influenced your recommendation.
5. Ask me to make or confirm the decision before moving to the next one.

Ask one decision at a time. Do not make assumptions when information is missing.

Keep the solution as simple as the product allows and call out anything that would be unnecessary over-engineering.

Once we have agreed on the important technical decisions, stop the interview and use those decisions to create `build-plan.md`.
